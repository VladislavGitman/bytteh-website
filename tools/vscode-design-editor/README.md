# Визуальный редактор BYTTEHMD для VS Code

Редактор работает в окне VS Code и меняет только цвета, размеры кнопок, скругления карточек, отступы секций и размер основного текста. Справа показывается локальная копия сайта.

## Запуск

1. Откройте в VS Code папку `bytteh-website`.
2. Откройте **Run and Debug** (`Ctrl+Shift+D`).
3. В списке конфигураций выберите **BYTTEHMD: редактор дизайна**.
4. Нажмите `F5`. Откроется отдельное окно VS Code для запуска редактора.
5. В новом окне нажмите `Ctrl+Shift+P`, выберите **BYTTEHMD: Открыть визуальный редактор дизайна**.

Изменения автоматически сохраняются в `design-overrides.css`. Кнопка **Вернуть исходный дизайн** возвращает исходные значения этого редактора. Чтобы опубликовать изменения на `bytteh-website.pages.dev`, отправьте файлы проекта в GitHub; Cloudflare Pages соберёт сайт автоматически.
